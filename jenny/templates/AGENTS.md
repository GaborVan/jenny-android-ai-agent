# Workspace Conventions

Project-specific preferences and recurring workflow conventions for this workspace.
Nothing is pre-filled: sections appear here as they are agreed, and a heading with
nothing under it does not belong in this file.

Not here: durable facts about the user (`USER.md`), personality and behaviour rules
(`SOUL.md`), project context and infrastructure (`memory/MEMORY.md`), reusable
procedures with concrete steps and output formats (`skills/<name>/SKILL.md`).
